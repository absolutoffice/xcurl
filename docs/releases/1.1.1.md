# xCurl 1.1.1 — release candidate (unpublished)

Date prepared: 05/11/2026. QA completed on Vulcano on 05/11/2026. No release tag was created during these checks; publication must be verified separately.

## Scope

Security-baseline PHP compatibility expansion only. Composer requires `>=8.4.27 <8.5 || >=8.5.12 <8.6`. PHP 8.4.26 and 8.5.11 are rejected; future PHP branches are excluded.

The 30 PHP source files in `src/` were verified byte-for-byte unchanged from the checked-out 1.1.0 baseline using `git diff --exit-code HEAD -- src/`. Public signatures, transport selection, TLS verification, redirect/retry policy, custom transport injection and mandatory runtime dependencies were not changed. `LICENSE` and `COPYING` remain included.

## Verified QA — Vulcano (05/11/2026)

- **Real runtimes:** PHP 8.4.27 and PHP 8.5.12; Composer 2.11.1.
- **Regression:** `tests/regression.php` passed under both real PHP interpreters.
- **Composer:** `composer validate --strict --no-check-lock`, `composer install` and `composer check-platform-reqs` passed under the tested PHP runtimes. Development dependencies were also installed in separate temporary directories for each interpreter; both platform checks passed.
- **Version boundaries:** isolated Composer consumer tests using simulated platforms rejected 8.4.26 and 8.5.11, and accepted 8.4.27 and 8.5.12. The installed package's fake-transport smoke checks passed.
- **Consumer installation from ZIP:** the ZIP was extracted to an isolated directory, installed into separate Composer path-repository consumers with PHP 8.4.27 and 8.5.12, and PSR-4 loading of the main transport factory and transport interface passed.
- **Static analysis:** PHPStan level 10 on `src/` passed under both PHP interpreters, with `treatPhpDocTypesAsCertain: false` in `phpstan.neon`.
- **Style:** PHP-CS-Fixer 3.95.28, `@PER-CS3.0`, checked all 30 `src/` and both `tests/` PHP files under PHP 8.4.27: zero findings after test-only formatting corrections.
- **Syntax:** all 32 PHP files in `src/` and `tests/` passed `php -l` under PHP 8.4.27 and PHP 8.5.12.
- **Distribution:** ZIP integrity and excluded-entry checks passed. `VERSION` was 1.1.1; `LICENSE`, `COPYING`, documentation, source and test files were present. `vendor/` and `composer.lock` were absent. The originally validated ZIP SHA-256 was `f30d9bcd342372904e04f47c1df079212d9a239ab865421203f575dc9052414d`.

## Limits and publication

- These tests are not an exhaustive live-network, TLS/PKI, proxy, SSRF, or backend-failure security audit. No claim is made that every real HTTPS environment was exercised.
- The ZIP containing this corrected documentation differs from the original validated ZIP and therefore has a **new SHA-256**. Content and integrity checks for the corrected archive should be recorded with its new digest. No runtime PHP or public API code was changed by this documentation correction.
- Publication, Packagist indexing, and the `v1.1.1` Git tag remain maintainer actions and are not established by the QA results.

The four earlier 1.1.0 practical PDF manuals remain historical; the PHP requirements above supersede their compatibility descriptions for this release candidate.
