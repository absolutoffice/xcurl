# xCurl 1.1.0

Release metadata date: 25 October 2026.

## Changes

- Raised the consumer PHP requirement to `^8.5.12` (8.5.12 or later, below 9.0) and the contributor `config.platform.php` baseline to `8.5.12`. Consumer platform checks still use the deployment runtime.
- Prepared Composer homepage/support metadata and aligned archive/export exclusions for local artifacts, caches, environment files and key material. Runtime code, licenses and regression tests remain distributed; no root Composer `version` field is required.
- Added isolated Composer consumer checks: reject simulated PHP 8.5.11, install a mirrored package on 8.5.12, load only installed `vendor/autoload.php`, exercise the public API with a fake transport, and inspect actual ZIP contents.
- Included ownership-safe download cleanup since the previous published snapshot: the client refuses pre-existing targets and removes only intermediate targets explicitly reported as exclusively created by completed attempts. Dependency-free regressions cover target ownership, no-body continuation and socket behavior.

## Installation

Prepared for the first stable Git tag, `v1.1.0`; earlier changelog versions do not establish published tags. Composer derives stable versions from Git tags, not the root `VERSION` file.

After tag publication, use the [GitHub VCS installation route](https://github.com/absolutoffice/xcurl/blob/v1.1.0/docs/INSTALLATION.md#stable-v110-through-github-vcs-after-tag-publication) with `absolutoffice/xcurl:1.1.0`. Without a VCS repository override, `composer require absolutoffice/xcurl:^1.1` is valid only after Packagist has indexed the release. `dev-main` remains a development option, not a stable pin. Local checks establish neither tag publication nor registry indexing.

## Validation and limits

- Local checks: `composer validate --strict --no-check-lock`, `composer test`, and `php tests/composer-consumer.php` on PHP 8.5.12 / Composer 2.10.3.
- Coverage is dependency-free regression, mirrored-source consumer installation and ZIP content inspection, not installation from the ZIP, GitHub or Packagist.
- Full HTTPS integration and developer-tool suites were not run. Historical PHP 8.5.11 / 14-gate QA claims remain historical and do not describe this release's validation.
